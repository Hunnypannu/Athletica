## Brand & Style

This design system embodies high-performance sports science, precision bio-tracking, and relentless athletic momentum. Built for elite competitors, dedicated hybrid athletes, and high-tier coaches, the aesthetic bridges brutal tactical readiness with clinical nutrition intelligence.

The visual style is **Hyper-Technical Dark Mode**: deep carbon textures, structural gridlines, crystalline data visualization, translucent glass containers, and high-frequency kinetic energy spikes. Interfaces feel like a Formula 1 telemetry dashboard crossed with an elite training facility terminal—dark, focused, hyper-responsive, and unsparingly legible.

Key visual pillars:
- **Kinetic Precision**: High-contrast focal points eliminate ambiguity. Vital stats, target heart rate zones, and macro calibrations stand out instantly.
- **Deep Immersion**: Rich slate and carbon foundations reduce ocular fatigue during 5:00 AM track drills or late-night macro logs.
- **Electric Ignition**: High-octane accents (electric volt, energized cyan, thermal orange) cut through slate layers to signal active workout intervals, threshold crossings, and critical nutrition targets.

## Colors

The palette is engineered around high contrast on pure dark surfaces, conforming strictly to WCAG AAA targets for numeric telemetry and primary actions.

### Surface Architecture
- **Base Canvas (`#0B0F15`)**: Deep carbon foundation for background canvas.
- **Surface Level 1 (`#131A24`)**: Recessed modules, outer container frames, and master sidebars.
- **Surface Level 2 (`#1E2736`)**: Elevated cards, telemetry modules, and input backings.
- **Surface Stroke (`#2A364A`)**: Razor-thin structural outlines creating boundary definition without visual clutter.

### Accents & Signal Colors
- **Electric Volt (`#D4FF00`)**: Primary driver. Signifies ready states, live sets, peak completion, active timers, and key calls-to-action.
- **Hyper Cyan (`#00F0FF`)**: Secondary driver. Used for hydration metrics, recovery scores, VO2 max metrics, and secondary interactive states.
- **Thermal Orange (`#FF5E00`)**: Tertiary driver. Designates high-strain heart rate zones, acute calorie deficit alerts, caloric burn rates, and threshold over-indexing.
- **Muted Content (`#8B9BB4`)**: Secondary labels, units of measure, and dormant navigational links.
- **Pure White (`#FFFFFF`)**: Primary metrics, headlines, and critical active values.

## Typography

The typographical structure leverages three distinct font roles:
1. **Space Grotesk** commands the editorial and high-impact structural levels. Its geometric anatomy and deliberate technical cuts deliver authoritative athletic grit.
2. **Inter** handles narrative clarity, descriptions, nutrition coaching logs, and complex exercise instructions, ensuring fatigue-free readability.
3. **JetBrains Mono** powers real-time metrics, macronutrient split tallies, splits, sets, heart rate readouts, and timestamps. It guarantees tabular numeric alignment across fast-updating dashboards.

All metadata labels and micro-metrics use uppercase tracking with `label-mono` or `label-caps` to evoke instrument cockpit panels.

## Layout & Spacing

The system runs on an 8px modular baseline grid with a fluid responsive structure:
- **Mobile (< 768px)**: 4-column layout, `margin-sm` (16px), `gutter-sm` (16px). Bottom-anchored action zones for single-thumb workout manipulation.
- **Tablet (768px - 1199px)**: 8-column layout, `margin` (24px), `gutter` (24px). Dual-pane layouts for split workout/nutrition scheduling.
- **Desktop (1200px+)**: 12-column layout, `margin-lg` (48px), `gutter-lg` (32px), capped at a 1440px inner max content container.

Modules snap to tight vertical clusters. High-density metrics pair closely via `space-xs` and `space-sm`, while top-level analytical clusters separate cleanly with `space-xl` to maintain scanning discipline.

## Elevation & Depth

This system avoids traditional light-scattering drop shadows, opting instead for **tactical luminescence and dark glassmorphic stratification**.

- **Base Stage**: `#0B0F15` deep carbon canvas.
- **Recessed Tray**: `#131A24` at 100% opacity with an inset 1px border (`#1E2736`) for embedded metric track rails.
- **Floating Glass Module**: Background `rgba(30, 39, 54, 0.65)` layered with `backdrop-filter: blur(16px)`, bound by a 1px border of `rgba(255, 255, 255, 0.08)`.
- **Active Kinetic State**: When a component, card, or target metric is active or selected, its border shifts to `rgba(212, 255, 0, 0.4)` and casts an ambient volt halo: `box-shadow: 0 0 24px -4px rgba(212, 255, 0, 0.22)`.
- **Critical Threshold Glow**: High strain and caloric alarms cast an orange corona: `box-shadow: 0 0 24px -4px rgba(255, 94, 0, 0.28)`.

## Shapes

The form language is disciplined, compact, and architectural. The default corner radius is soft (`roundedness: 1` / 4px base), communicating industrial precision rather than playful softness.

- **Micro elements & badges**: 4px radius (`rounded-sm`).
- **Cards, telemetry tiles, and modals**: 8px radius (`rounded-lg`).
- **Input fields & button controls**: 6px radius (`rounded-md`).
- **Progress bars and track fills**: Strictly flat or clipped chamfers (0px to 2px max radius) to keep data displays crisp and razor-accurate.
- **Pill overrides**: Restricted solely to binary live tags (e.g., `● REC`, `LIVE COACHING`) using a 9999px fully rounded enclosure.

## Components

### Buttons
- **Primary Kinetic Button**: Background `#D4FF00`, text `#0B0F15` (`Space Grotesk`, bold, uppercase, tracking +0.04em). Height: 48px. Hover: subtle brightness lift with `box-shadow: 0 0 20px rgba(212, 255, 0, 0.45)`. Active: micro scale press (0.98).
- **Secondary Ghost Button**: Surface `rgba(30, 39, 54, 0.5)` with 1px border `#2A364A`, text `#FFFFFF`. Hover: border `#00F0FF`, text `#00F0FF`, subtle cyan ambient wash.
- **Destructive/High-Strain Button**: Surface `rgba(255, 94, 0, 0.1)`, 1px border `rgba(255, 94, 0, 0.4)`, text `#FF5E00`.

### Cards & Telemetry Tiles
- Encapsulated in the dark glass surface (`rgba(30, 39, 54, 0.65)`), 8px corner radius, 1px perimeter border of `#2A364A`.
- Header area features a distinct uppercase category label in `label-mono` (`#8B9BB4`) paired with an optional real-time pulse indicator.
- Metric values sit prominently in `metric-xl` or `metric-lg` (`JetBrains Mono`, `#FFFFFF`), accompanied by atomic units in lowercase volt or cyan.

### Chips & Badges
- **Status Badges**: Semi-translucent base tint with an integrated 6px luminous dot.
  - Active / Peaking: Base `rgba(212, 255, 0, 0.12)`, text `#D4FF00`, 1px border `rgba(212, 255, 0, 0.3)`.
  - Recovery / Hydration: Base `rgba(0, 240, 255, 0.12)`, text `#00F0FF`, 1px border `rgba(0, 240, 255, 0.3)`.
  - Max Effort / Deficit: Base `rgba(255, 94, 0, 0.12)`, text `#FF5E00`, 1px border `rgba(255, 94, 0, 0.3)`.
- **Filter Chips**: Height 32px, shape 4px, surface `#131A24`, border `#2A364A`. Selected state triggers electric volt text and an active volt bottom border (2px).

### Input Fields
- Dark input cavity: `#0B0F15`, 44px height, 1px border `#2A364A`, text `#FFFFFF`, typography `JetBrains Mono` 15px.
- Focus state: Border transitions to `#00F0FF` with a 2px outer cyan wash (`rgba(0, 240, 255, 0.15)`).
- Trailing metric unit indicators (e.g., `kcal`, `bpm`, `g`, `reps`) rendered in `label-mono` (`#8B9BB4`).

### Selection Controls (Checkboxes & Radios)
- Checkboxes: 20x20px square, 3px border radius, `#0B0F15` base, 1px `#2A364A` border. Checked state fills with `#D4FF00`, rendering a jet-black precision check icon.
- Radios: Concentric rings; active state reveals an illuminated `#00F0FF` core point with an electric ambient glow.

### Specialized Fitness/Nutrition Modules
- **Macro Split Rail**: Multi-segment bar, 8px height, 2px border radius. Protein (Electric Volt `#D4FF00`), Carbohydrates (Hyper Cyan `#00F0FF`), Fats (Thermal Orange `#FF5E00`). Empty deficit depicted with a slashed carbon texture.
- **Heart Rate Zone Tracker**: 5-tier stepped vertical equalizer with real-time zone pinging and peak threshold luminescence.
